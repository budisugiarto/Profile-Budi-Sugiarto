# Budi Sugiarto Portfolio

Personal Professional & Academic Portfolio built with Next.js, TypeScript, Tailwind CSS, MDX, Framer Motion, and Lucide Icons.

## Setup

Install Node.js LTS first, then run:

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Pages

- `/` Home
- `/about` About
- `/experience` Experience
- `/projects` Projects
- `/achievement` Achievement
- `/academia` Academia
- `/insight` Insight
- `/contact` Contact

MDX content can be added under `content/` and is enabled through `next.config.mjs`.
